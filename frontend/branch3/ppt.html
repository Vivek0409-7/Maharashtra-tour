Introduction

Understanding Stack Data Structure & Fundamentals

What is a Stack?

A linear data structure where element insertion and deletion are restricted to a single end called the Top of Stack.

LIFO Principle

Stacks follow Last In, First Out (LIFO). The last element pushed into the stack is the very first one to be removed.

Basic Operations

  • PUSH: Insert tag onto the stack top ($O(1)$)
  • POP: Remove tag from top of stack ($O(1)$)
  • TOP / PEEK: View top tag without removing ($O(1)$)

Problem Statement

HTML Tag Validation & Scope Hierarchy Verification

What Problem is Being Solved?

In HTML markup, opening tags must match corresponding closing tags in strict nested hierarchy.

Mismatched Example:
<div><p>Hello</div></p>
Error: </div> closes out of order before <p>!

Why is Stack Suitable for this Problem?

  • Nested Tag Symmetry: The most recently opened tag MUST be closed first. This matches LIFO perfectly.
  • Linear Execution: Validates input string in single $O(N)$ pass.
  • Instant Error Triggering: Detects premature closure or unmatched end tags immediately.

Proposed Solution / Algorithm

Step-by-step logic for checking tag balance

1

Read Code

Read multi-line HTML string until "END" flag.

2

Extract Tag

Scan string for < and > markers. Skip <!DOCTYPE>.

3

Push / Pop

Push opening tags. If closing tag, check if top matches; then pop.

4

Verify State

If stack is empty at end → Valid. Else → Invalid.

Decision Rule:
• If tag starts with '/' → tag_name = tag.substr(1);
• If s.empty() or s.top() != tag_name → Return "Invalid HTML!"
• Else → s.pop();

Implementation

C++ Source Code Snippet (as written in project)

#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<string> s;
    string line, html;
    while (getline(cin, line)) {
        if (line == "END") break;
        html += line;
    }
    for (int i = 0; i < html.length(); i++) {
        if (html[i] == '<') {
            int j = html.find('>', i);
            string tag = html.substr(i + 1, j - i - 1);
            if (tag[0] == '!') continue; // Ignore DOCTYPE
            if (tag[0] == '/') {
                string name = tag.substr(1);
                if (s.empty() || s.top() != name) {
                    cout << "Invalid HTML!" << endl; return 0;
                }
                cout << "POP: " << name << endl; s.pop();
            } else {
                s.push(tag); cout << "PUSH: " << tag << endl;
            }
            i = j;
        }
    }
    cout << (s.empty() ? "\n Valid HTML!" : "\n Invalid HTML!");
}

Language & Data Structure

Implemented in C++ using Standard Template Library (std::stack<string>).

Key Functions

  • html.find('>', i) locates closing tag brace
  • html.substr() extracts tag name
  • s.push() saves open tags
  • s.pop() matches closed tags

Applications & Advantages

Practical Applications of Stacks in Real-world Parsing Systems

Applications of Stack

  • Web Browsers (DOM Parsers): Validates HTML/XML before rendering the document tree.
  • Compiler Syntax Checkers: Verifies parentheses `()`, braces `{}`, and brackets `[]` balance in programming languages.
  • XML Validation Engines: Used in SOAP web services and configuration file parsers.

Advantages of Using Stack

  • High Efficiency: Time complexity is linear $O(N)$ and Space complexity is $O(D)$ where $D$ is nesting depth.
  • Low Memory Footprint: Stores only active open tags rather than storing entire DOM nodes.
  • Simplicity: Straightforward implementation using STL `std::stack`.
